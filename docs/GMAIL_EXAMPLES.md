# Casos mínimos de extracción

## BCP

```text
From: notificaciones@notificacionesbcp.com.pe
Subject: Constancia de Transferencia Entre mis Cuentas - Servicio de Notificaciones BCP
Sent-by: em4534.notificacionesbcp.com.pe

Monto: S/ 1,250.00
Fecha: 18/09/2026
```

Resultado: `Transferencia`, PEN 1250.00, estado `Por revisar`, excluida del presupuesto
hasta asignar cuenta de origen y destino.

## Interbank

```text
From: servicioalcliente@netinterbank.com.pe
Subject: Raul, realizaste un consumo con tu Tarjeta Interbank Visa Débito Benefit
Sent-by: gnt.estadocuenta.interbank.pe

Comercio: PLAZA VEA
Monto: S/ 87.60
Fecha: 18/09/2026
```

Resultado: `Gasto`, PEN 87.60, comercio `PLAZA VEA`, categoría `Alimentación`, estado
`Por revisar`.
